# FCAJ internship report (Thái Trung Kiên)

My internship report for the AWS First Cloud AI Journey programme. The site is built with Hugo from the
[FCJ workshop template](https://github.com/thienluhoan/fcj-workshop-template) (commit `c49d601`).

The published site is at https://kina2711.github.io/fcaj-internship-report/

Pages live in `content/`. Each page has an English version (`_index.md`) and a Vietnamese one (`_index.vi.md`).
I add each section once its content is written.

To preview locally, run `hugo server` and open http://localhost:1313/fcaj-internship-report/

Pushing to `main` runs `.github/workflows/hugo.yml`, which builds the site and publishes it to the `gh-pages` branch.
